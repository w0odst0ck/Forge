**关键决策/认知升级（全部沉淀进复习本 notes.md）：**

1. **D2 Q4（防抖时间戳 vs delay）**：两个致命问题定性 = **忙等阻塞**（CPU 停摆；ISR 里 delay = 主循环挂起 + 看门狗超时复位）+ **时长拍脑袋**（短了防不住 5-20ms 弹跳，长了吞掉合法连按；delay 期间丢的是**真事件**）。时间戳 = 非阻塞判定（微秒级，ISR 安全），丢的是噪声不是事件。
   - **纠正概念**：中断每次下降沿由**硬件无条件触发**，时间戳不是触发开关，是 ISR 内仲裁（算不算有效）——**触发 ≠ 有效，硬件触发 vs 软件过滤两个层面**。类比：webhook 每次都推，消费端去重/冷却。

2. **D2 深入一问（FreeRTOS 队列）已回收**：用户答"优先级排序 + 中断打断耗时任务"——方向对但漏了裸机局限：**ISR 置标志返回后主循环还在 delay 剩余时间，消费照样等**（中断打断的是执行，不是顺序）。RTOS 真正机制：事件**进队列**（ISR=生产者）+ 按键处理独立任务高优先级（消费者）+ **vTaskDelay 让出 CPU**（暂停自己不是暂停世界）→ 调度器级抢占，响应毫秒级。记忆点：**事件不进标志位、进队列**。

3. **D3 Q1（占空比 vs 频率）**：1% ≈ 灭但**0% 才真灭**（平均光能 = 满亮 × 占空比）；20Hz < 视觉暂留下限（~60Hz）→ 频闪（IEEE 1789，相机频闪带）。两个独立维度：占空比 = 亮度旋钮，频率 = 闪烁消除器。

4. **D3 Q2（PWM vs 模拟调流）**：PWM 恒流 = 色温稳（电流恒定→波长不漂）+ 效率 90%+；调流 = 色温漂 + 损耗大（(V_in−V_LED)×I 全变热，越暗越差）。**行业决策框架：EMI 是工程问题（频率抖动/软开关/滤波器可修），色温/效率是原理问题（无解）——选"原理级优点+工程级缺点"的路**。0-10V/DALI 只是上层协议，驱动底层肌肉就是 PWM/恒流（W3 深挖）。

**D3 Q3（分辨率 8bit vs 16bit）已讲未答**：细分粒度 256 vs 65536 级；韦伯-费希纳定律（感知 ∝ log 光强）→ 人眼暗区最敏感 → 8bit 低亮度档位阶梯跳变可见、亮区看不出；高端驱动拼调光深度（1%→0.1%）。
