# W1-D7 · 复盘 + W2 衔接

> 验证标准：完成复盘笔记，明确 W2 前置清单

## 一、W1 → W2 能力映射表（为什么 W1 不是孤立一周）

W2（Modbus 主从 + MQTT 桥接）的每个任务，都需要 W1 的对应能力：

| W2 任务 | 所需 W1 能力 | 对应 demo |
|---------|-------------|-----------|
| 理解 Modbus RTU 帧结构 | UART 帧概念（起始位/数据位/CRC）| D4 |
| pymodbus 从站模拟灯具（寄存器=亮度）| "设备=寄存器集合"的心智模型 + 调光概念 | D3+D4 |
| 主站轮询 + 写亮度 | 读写时序、超时处理 | D4 |
| 多从站寻址（3 个灯节点）| I2C 多设备寻址的思路（地址冲突教训）| D5 |
| 掉线容错 | D4 的 timeout 分支实验（删线观察）| D4 |
| MQTT 桥接（Modbus→MQTT）| "数据链路"概念（传感器→串口→上位机）| D5 组合挑战 |

**一句话**：W1 给了你"嵌入式设备怎么想"的手感；W2 让 PC 用工业标准协议（Modbus）跟设备对话。
